# Конфиденциальность и безопасность

Коротко: «Точка» меняет четыре знака в русской раскладке и больше ничего не делает. Она не записывает набранный текст, не выходит в интернет и не собирает статистику.

## Зачем приложению доступ к клавиатуре

macOS разрешает менять нажатия клавиш только программам с разрешением «Универсальный доступ» (Accessibility). Без него «Точка» не может заменить знак. Это то же разрешение, которое используют Karabiner-Elements, Rectangle, Raycast и другие утилиты.

Разрешение даёт технически широкий доступ, поэтому проверить, что программа с ним делает, можно по коду. Весь код — около 700 строк на Swift:

| Что | Где в коде |
| --- | --- |
| Подписка на события клавиатуры: только нажатие и отпускание | [`Sources/main.swift` — `installTap`](Sources/main.swift#L122-L141) |
| Какие клавиши трогаются: только коды 44, 26, 22 (`/`, `7`, `6` на английской раскладке) | [`Sources/Remapping.swift` — `transform`](Sources/Remapping.swift#L51-L66) |
| Правила замены: четыре сочетания, только раскладка `com.apple.keylayout.Russian`, без Command/Control/Option/Fn | [`Sources/Remapping.swift` — `replacement`](Sources/Remapping.swift#L14-L24) |

Обработчик видит событие, решает, менять ли знак, и сразу отдаёт событие дальше. Запоминаются только коды клавиш, которые зажаты прямо сейчас, — чтобы нажатие и отпускание совпали. При отпускании код удаляется.

## Чего приложение не делает

- **Не записывает ввод.** Нажатия нигде не сохраняются: ни в файлы, ни в память дольше, чем клавиша зажата.
- **Не использует сеть.** В коде нет сетевых запросов, а в программе нет сетевых библиотек. Единственный адрес внутри — `https://github.com/rolexx671/Tochka`. Его открывает браузер, и только когда ты выбираешь пункт меню «Исходный код и конфиденциальность…».
- **Не читает буфер обмена, экран, файлы и другие приложения.**
- **Не собирает аналитику и отчёты о сбоях.**
- **Не работает в полях паролей.** Когда macOS включает защищённый ввод, она сама перестаёт передавать нажатия таким программам.

## Что приложение хранит

Только свои настройки в стандартном хранилище macOS (`defaults read io.github.rolexx671.tochka`):

| Ключ | Значение |
| --- | --- |
| `paused` | выключена ли «Точка» значком в строке меню |
| `setupCompleted` | пройдена ли первая настройка |
| `loginItemAttempted` | предлагался ли уже автозапуск |
| `NSWindow Frame TochkaSetupWindow`, `NSStatusItem …` | положение окна и значка (сохраняет macOS) |

## Как проверить самому

```sh
# 1. Сетевых соединений нет (пустой вывод)
lsof -nP -a -p "$(pgrep -x Tochka)" -i

# 2. Что приложение сохранило
defaults read io.github.rolexx671.tochka

# 3. Какие адреса вшиты в программу
strings -a /Applications/Точка.app/Contents/MacOS/Tochka | grep -i http
```

Ещё можно поставить файрвол вроде [LuLu](https://objective-see.org/products/lulu.html): он покажет, что «Точка» не пытается выйти в сеть.

## Откуда берётся файл для скачивания

`Tochka.dmg` в [релизах](https://github.com/rolexx671/Tochka/releases) собирает GitHub Actions из открытого кода этого репозитория, а не компьютер автора. GitHub подписывает сборку аттестацией происхождения (build provenance). Проверить, что твой файл собран именно из этого репозитория:

```sh
gh attestation verify Tochka.dmg --repo rolexx671/Tochka
```

Или сравни контрольную сумму с `Tochka.dmg.sha256` из того же релиза:

```sh
shasum -a 256 Tochka.dmg
```

## Почему macOS предупреждает при первом запуске

Автор не платит Apple $99 в год за подпись Developer ID. Поэтому macOS не знает, кто сделал приложение, и просит подтверждение вручную. Это не значит, что программа опасна, но и проверкой Apple не является. Ей служат открытый код и проверяемая сборка, описанные выше.
