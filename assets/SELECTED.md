# Выбранная иконка

Пользователь утвердил «Чистое стекло» из второй серии Liquid Glass.

Источник: `liquid-glass-set-02/01.png`.
Рабочая копия: `logo.png`.
ICNS пересобирается из рабочей копии через `scripts/make-icon.sh`.
Имя образа для распространения: **Точка.dmg**. Внутренние CFBundleVersion и CFBundleShortVersionString сохраняются для macOS и не входят в имя приложения или образа.
