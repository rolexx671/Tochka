# План вывода сайта «Точки» в топ Яндекса

Исходные данные: сайта пока нет, аудитория — Россия (≈ 90 % показов), спрос см. [demand-analysis.md](demand-analysis.md). Цель: топ-3 Яндекса по ядру «точка на макбуке» и кластеру «запятая/знаки на макбуке» за 3–6 месяцев.

## Этап 0. Основа (неделя 1)
- Домен: .ru (желательно с ключом по теме: например «tochka-mac.ru»), хостинг на российской площадке (низкий пинг, стабильный доступ из РФ). Проверить, что домен «чистый» (история в Wayback, Вебмастер).
- HTTPS (Let's Encrypt), редирект www → без www, один главный адрес.
- Яндекс Вебмастер: подтвердить права, указать регион (Россия), загрузить sitemap.xml и robots.txt.
- Яндекс Метрика: счётчик, цели («скачал DMG», «клик по инструкции», «просмотр демо»), вебвизор.
- Яндекс ID организации и Яндекс Бизнес (если есть юрлицо/ИП), страница в «Яндекс Бизнес»/Справочнике.

## Этап 1. Структура сайта (неделя 1–2)
Один сайт, плоская структура, каждая страница под свой кластер:
1. Главная: «Точка на макбуке в русской раскладке» (ядро: точка/запятая; вся демонстрация, GIF/видео, кнопка скачивания).
2. /kak-postavit-tochku-na-makbuke — инструкция без приложения (системные способы), с мягким предложением приложения.
3. /zapyataya-na-makbuke — кластер «запятая» (≈ 2,1 тыс./мес.).
4. /vopros-i-slesh-na-makbuke — «?», «/», «\\» (Shift+7/Shift+6).
5. /raskladka-russkaya-makbuk — общая страница про русскую раскладку Mac.
6. /faq — «не работает», «Универсальный доступ», совместимость macOS 13+, Intel/Apple Silicon.
7. /download, /privacy, /contacts. Страницы доверия: о проекте, версия и changelog.

## Этап 2. Семантика (неделя 2)
- Ядро (Вордстат, 05.09–04.10.2026): точка на макбуке 2 131; как поставить точку 863; в русской раскладке 305; на клавиатуре макбука 291; где точка 174; запятая на макбуке 1 930; как поставить запятую 930.
- Расширить: Вордстат «Похожие», подсказки Яндекса, «Поисковые запросы» в Вебмастере, Яндекс Wordstat по «макбук нео/air/pro», «Mac mini/iMac» (аналогичная раскладка).
- Кластеризация по интенту: «как» (инструкция), «где» (картинка/схема), «не работает», «приложение/программа/скачать». Один кластер — одна страница; каннибализацию не допускать.
- Исключить шум: «точка доступа», «точки на экране».

## Этап 3. Контент и on-page (неделя 2–4)
- Title до 60–70 симв.: «Точка на макбуке в русской раскладке — как поставить, программа «Точка»»; H1 с главным запросом, один H1.
- В первых 150 словах прямой ответ («Клавиша справа от Ю» + как включить), далее скриншоты с подписями и alt, видео/GIF с демонстрацией.
- Блоки под колдунщики/быстрые ответы Яндекса: короткий ответ 40–60 слов, нумерованные шаги, таблица клавиш (как в README), FAQ.
- Разметка: schema.org SoftwareApplication, FAQPage, HowTo, BreadcrumbList; Open Graph и Twitter-превью.
- Уникальные тексты, без переоптимизации; регионально не привязываться, но «для macOS в России» допустимо.
- Дубль-страницы: каноникал, теги noindex для служебных.

## Этап 4. Технические факторы (неделя 3–4)
- Скорость: Core Web Vitals (Яндекс учитывает «Скорость загрузки»), изображения WebP/AVIF, шрифты системные, статика через СDN с узлами в РФ.
- Мобильная версия (адаптив), значок/фавикон, 404/301 обработка.
- Яндекс Вебмастер: следить за «Диагностикой», ИКС, ошибками индексации; ускорить индексацию через «Переобход страниц» и IndexNow.
- Скачивание DMG: прямой файл с нормального хостинга/GitHub Releases-зеркало; ссылка с контрольной суммой и страницей «безопасность» (приложение пока без Developer ID/notarization — в тексте честно объяснить предупреждение Gatekeeper, это снижает отказы).

## Этап 5. Поведенческие факторы (месяц 2–6)
Яндекс активно учитывает поведение: цели — длительное чтение, отсутствие возврата в выдачу, клики на скачивание.
- Сниппеты: заманчивые Title/Description, быстрые ссылки (Вебмастер), «Турбо»/превью не требуются.
- Сильный первый экран, видео-демо, понятный CTA, минимум рекламы.
- Метрика: отслеживать отказы по запросам, улучшать страницы с высоким возвратом в выдачу.

## Этап 6. Ссылки и упоминания (месяц 2–6)
- Только белые, тематические: Хабр (статья «Как я решил проблему с точкой на русской раскладке macOS»), vc.ru, Pikabu, DTF по необходимости, русскоязычные Mac-сообщества (Telegram-каналы, форумы iPhones.ru/appleinsider.ru/macdigger), YouTube-обзор с описанием.
- Каталоги приложений для macOS (RU-обзоры, подборки «утилиты для Mac»), GitHub-репозиторий со ссылкой на сайт.
- Ответы на вопросы в Яндекс Кью/Дзен/Тематических форумах (без спама, с пользой).
- Не покупать массовые ссылки: риск санкций Яндекса (фильтр «Ссылочный взрыв»).

## Этап 7. Расширение трафика (месяц 3+)
- Длинный хвост: статьи «Раскладка Mac vs Windows», «Горячие клавиши Mac для русскоязычных», «Как поменять раскладку на Mac».
- Яндекс Дзен-канал/Telegram-канал проекта для вторичного трафика и упоминаний.
- Яндекс Директ (тест): поисковая реклама по ядру на 1–2 недели для проверки конверсии и сбора реальных запросов (бюджет ≈ 5–10 тыс. ₽), параллельно служит ориентиром для SEO.

## Метрики и контроль

| Страниц в индексе | 8–10 | 12–20 | 25+ |
| Позиция по «точка на макбуке» | топ-50 | топ-10 | топ-3 |

| Конверсия в скачивание | ≥ 10 % | ≥ 15 % | ≥ 20 % |

Инструменты: Яндекс Вебмастер, Метрика, Вордстат, AllPositions/Топвизор (замер позиций по региону), Searchmetrics-аналоги по желанию.

## Риски
- Небольшой потолок спроса (≈ 3,8 тыс./мес. по теме) — рассматривать сайт как воронку установки, а не как массовый канал.
- Сезонность: летом −20 %; запуск и контент лучше выпускать к сентябрю–октябрю.
- Конкуренты в выдаче: форумы и Яндекс Кью/Дзен. Побеждать структурой, видео и быстрым ответом.
- Приложение без notarization: пользователи могут уходить после предупреждения macOS; решение — Developer ID и notarization (см. distribution/RELEASE.md).
