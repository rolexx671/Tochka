## 4. Google Trends (Россия)

- Запросы «где точка на макбуке», «как поставить точку на макбуке», «точка на клавиатуре макбук» за 12 мес. и «точка на макбуке» / «запятая на макбуке» за 5 лет дают почти нулевую линию с единичными всплесками (значения 0–1, отдельные пики 50–100 вне тренда).
- Вывод: в России Google по этим запросам даёт неразличимо малые объёмы для Trends, весь измеримый спрос сосредоточен в Яндексе. Месячную и годовую динамику по Google нельзя построить надёжно (не хватает объёма); Keyword Planner требует аккаунт Google Ads и в РФ не отдаёт данные по показам, поэтому не использован.

## 5. Выводы

1. Спрос реальный, узкий и устойчивый: ≈ 3,8 тыс. показов в месяц по теме, около 1,8–2,1 тыс. по ядру «точка на макбуке», рост +11 % г/г.
2. Намерение запросов инструкционное («как поставить», «где»), пользователи ищут решение проблемы раскладки. Это идеальный повод для страницы-ответа с демонстрацией и загрузкой приложения.
3. Основная аудитория: Россия, и почти половина из Москвы/СПб/центра. Яндекс — основной канал.
4. Потолок органического трафика: при топ-3 по ядру реалистично 25–40 % CTR, то есть 700–1 500 визитов в месяц с основных запросов и до 1,5–2 тыс. с учётом хвоста. Значит, цель — не массовый трафик, а высокая конверсия в установку.
5. Расширение семантики: у пользователей та же проблема с «?», «/», «,» — на нашем сайте их нужно покрывать (приложение переназначает 4 клавиши).

## 6. Ограничения

- Вордстат показывает показы, а не уникальных пользователей; данные по устройствам (десктоп/смартфон) не сняты.
- Google-часть без Keyword Planner (нужен рекламный аккаунт Google Ads).
- Мобильные запросы с iPhone/iPad с этой раскладкой не связаны, возможна доля нерелевантных показов (оценить вручную по выдаче).
